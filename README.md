## Analyses

### [Dog Ownership Across US Metro Areas](analyses/dog_ownership/)

Estimates dog ownership rates for ~530 US metro areas using veterinarian employment
density as a proxy, with income correlation analysis and an interactive choropleth map.

| File | Description |
|------|-------------|
| [map.html](analyses/dog_ownership/map.html) | Interactive US map — state fill by dog rate, metro circles by population, top/bottom 20 metros highlighted |
| [notebook.pdf](analyses/dog_ownership/notebook.pdf) | Full analysis notebook with methodology, charts, and findings |
